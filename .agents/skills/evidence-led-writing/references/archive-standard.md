# 事实研究与留档标准

## 1. 留档对象分层

1. **原始来源材料**：档案、书籍/论文片段、报刊、演讲、口述/访谈、数据集、网页快照等。保存原始文件或可复查定位；不在原件上直接改写。
2. **来源记录**：说明材料是什么、从哪里取得、由谁形成、何时形成、如何定位、能证明什么/不能证明什么。
3. **事实主张记录**：单一、可判断的事实陈述，列出支持、反证、范围和置信度。
4. **研究日志**：搜索过什么、查看过什么、为何纳入/排除、何处无法访问、接下来查什么。
5. **分析记录**：从事实到解释的推理链、假设、替代解释和不确定性。
6. **作者判断与文章版本**：作者的评价标准、政治判断、确认状态及各版草稿的变化。

不得把上述层次合并成一份“资料综述”后丢弃来源路径。

## 2. 来源登记必填信息

每个来源使用稳定 ID，例如 `S-0001`，至少登记：

- 标题、作者/机构、材料类型、形成日期、出版/公开日期、语言；
- 档案馆/数据库/出版物/网站、档案号或稳定链接、访问日期；
- 原始文件路径或可复查位置、文件版本/页数；
- 引用所需定位（页码、段落、文件页、时间码、数据库记录号）；
- 来源与事件的距离、作者可获得的信息、机构目标/潜在偏见、已知限制；
- 与其他来源的关系：独立形成、转引、共同来源、同一档案的不同副本；
- 支持或反驳的事实主张 ID。

若来源无法保存全文，登记获取限制、检索结果页、引用位置和下次复查方法。对于有版权或隐私限制的材料，遵循访问许可，只留必要书目信息和合法的短摘录。

## 3. 事实主张拆分与证据

一条主张只包含一个可核验命题，尽量写清人物/机构、行动、时间、地点、对象和数量口径。避免“某国操纵了事件”这类混合了行动、意图和因果结论的句子；应拆成可分别核查的主张。

每条主张至少记录：

- 稳定 ID（例如 `C-0001`）；准确表述及类型：事实、估算、意图、因果、解释或评价；
- 适用时间/地点/群体范围；当前状态：待查、部分支持、争议、暂确认、撤回；
- 支持来源 ID、反证来源 ID、原文摘录及精确定位；
- 转述或翻译是否为 AI 生成、由谁复核；
- 竞争解释、缺失材料和下一步核查动作；
- 来源可靠度、事实置信度、因果置信度，分别记录。

引文必须与原文逐字一致并保留上下文。原文和译文分开保存；译文标记译者/模型、日期和复核状态。涉及非英语材料时，保留原语言标题/术语；关键措辞不确定时并列译法。

## 4. 置信度：分维度记录

置信度用于说明目前证据状况，不是数字化的真理保证。每个维度写简短理由，不只打标签。

- **来源可靠度**：材料真实性、来源链、作者当时的接触能力、形成目的、是否完整。注明“原件已核”“仅见转录”“出处待核”等。
- **事实置信度**：高：精确主张由可定位材料直接支持，并有独立证据交叉印证，关键范围清楚；中：可信材料支持，但存在来源单一、口径差异或范围不全；低：材料间接、回忆性、语义含糊或有重要反证；未核：目前无可检查证据。
- **因果置信度**：高：存在明确机制证据，时间、行动者和结果链条相互吻合，替代解释经检验；中：机制合理且部分支持，但关键环节或替代解释未排除；低：主要依据相关性、推断或单一有立场的陈述。

来源可靠度高不自动意味着其叙述无偏；多个来源数量多也不等于独立，因为它们可能转引同一材料。档案沉默只有在文件本应记载该信息、档案完整且搜索充分时，才能作为有限的负面证据。

## 5. 检索日志与覆盖度

每次实质检索都记录：日期/时区、研究者、数据库/档案馆/搜索引擎、原样检索式、语言、时间/地域/文献类型过滤、浏览的结果范围、保留来源 ID、排除理由、访问失败、下一步查询。

在研究开始时建立覆盖矩阵，至少按以下维度拆分：

- 研究问题与具体可核验命题；
- 时段、地点、行动者/机构；
- 来源类型与档案持有人；
- 语言；
- 涉及的行动机制（如外交、情报、军事、经济、宣传、地区网络）；
- 已检索、待检索、不可访问、证据不足等状态。

“全面搜集”应表述为覆盖了哪些可检索范围、仍有哪些盲区，不能声称穷尽所有材料。停止检索前说明：覆盖矩阵中的关键格是否有材料；新检索是否持续带来新的独立来源/事实；哪些重要档案未开放或未能访问；继续检索的预期收益和成本。

## 6. 来源对照与争议处理

- 关键结论优先追溯到原始记录，同时与独立的学术研究、区域材料和不同立场来源对照。
- 原始材料不是中立事实：外交电报、情报评估、宣传材料、党派文件和军方报告均需按其功能读取。
- 二手研究应记录引用链。若多篇著作都依据同一档案或同一回忆录，登记为共同来源，避免误算作多份独立证据。
- 对冲突数据并列记录定义、统计时间、地域、样本和来源；不得为方便叙事取一个数字而隐藏差异。
- 对争议性归因，分别核验“行动发生”“行动者/对象”“意图”“机制”“效果”和“因果贡献”。不把其中一项的证据当作其他项的证明。

## 7. 文件与版本管理

- 使用稳定 ID，不因改标题而更改已被引用的 ID。
- 建议命名：`S-0001_机构或作者_短标题_年份.ext`、`C-0001.md`、`search-YYYY-MM-DD-序号`。
- 将原始材料、工作摘录、分析、作者判断和文章草稿分别存放；原件只读保存。
- 每次重要修改登记日期、修改者、变更内容、依据、受影响的主张/分析/草稿和是否经作者确认。
- 禁止无记录地覆盖、删去冲突来源、回填搜索日期或把计划检索改写成已完成。
