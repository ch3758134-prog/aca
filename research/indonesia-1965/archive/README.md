# 研究档案结构与留存规则

`records/` 当前保存来源登记、事实主张、检索日志、覆盖矩阵、时间线、人物关系和外国介入机制表。目录说明见 `records/README.md`。

- `sources/original/`：依法、依许可保存的原始档案、法律文本、扫描件或网页快照；尽可能只读。
- `sources/working-copies/`：OCR、翻译、个人摘录、格式转换件；标注来源ID和处理记录。
- `records/`：检索过程、来源、事实主张、争议和覆盖情况。
- `analysis/`：分层分析备忘录及版本；事实阶段不提前写作者政治判断。
- `author-decisions/`：作者立场、作者决策与确认记录；目前作者立场文件未开放。
- `drafts/`：文章提纲、各版草稿和引文审计。
- `manifests/`：文件清单、哈希值、访问状态和最终交付清单。

每个来源保留原始标题、作者/机构、形成日期、网址/档案号、访问日期、精确定位和来源ID。不能复制全文时保留可复查定位与访问限制；不可把整本有版权著作复制进仓库。公开来源的搜索摘要只用作发现线索。

目前仓库为公开 GitHub 仓库。只提交适于公开的研究记录和合法可分享材料；不得提交作者未开放的私人立场或封闭档案内容。
