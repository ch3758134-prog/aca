# 研究档案目录约定

开始收集资料后，建议在此目录下建立以下子目录；不要将原始来源与分析草稿混放。

- `sources/original/`：依法、依许可保存的原始文件或网页快照；尽可能只读。
- `sources/working-copies/`：OCR、个人摘录、格式转换件；标注来源 ID 和处理记录。
- `records/`：来源登记、事实主张、检索日志、覆盖矩阵和时间线。
- `analysis/`：分层分析备忘录及其版本。
- `author-decisions/`：作者立场、确认记录和研究决策日志；按阶段控制是否开放给 AI。
- `drafts/`：文章提纲、各版草稿和引文审计。
- `manifests/`：阶段访问清单、文件清单、版本/校验值和最终交付清单。

每个保存文件都应关联 source ID，并保留原文件名、来源 URL/档案号、访问日期和转换说明。不能保存原件时，登记限制及可复查路径。访问控制需求较高时，把 `author-decisions/` 或尚未开放的来源放在独立工作区，而不是依赖本 README 或提示词限制。
