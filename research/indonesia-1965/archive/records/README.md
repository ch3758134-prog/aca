# 首轮研究记录

本目录记录2026-11-08启动的首轮持续检索，阶段为来源发现与事实核验。检索没有固定最早年份；任何与苏加诺、印尼国家与社会结构、1965事件、暴力、外国介入或权力转移相关的前史都可扩展。此处记录的是截至各条 `accessed_date` 已检查的材料，不是完成报告。

## 文件

- `source-register.csv`：稳定来源ID、书目信息、精确定位、访问/全文状态和来源限制。
- `claim-ledger.csv`：单一事实主张、支持/反证、事实置信度、因果置信度和待查动作。
- `search-log.csv`：每轮原样检索式、语言、范围、保留来源和检索缺口。
- `coverage-matrix.csv`：时期、地区、人物、国家、渠道、来源类型和覆盖状态。
- `chronology.md`：由事实主张构成的临时时间线。
- `actor-dossiers.md`：人物履历、亲属/师友/政治网络及关系证据。
- `foreign-intervention-matrix.md`：国家、行动渠道、计划/批准/执行/效果证据分栏。

## 状态和置信度约定

- `verified_text`：已打开对应法律文本或文件正文；仍要按材料目的审读。
- `abstract_only`：仅核查期刊/出版社/机构摘要；不代表读过全文。
- `metadata_or_catalog_only`：只核查书目或档案目录；尚未核查档案内容。
- `search_snippet_only`：仅有搜索摘要线索；不作为已确认事实依据。
- 置信度用于表达当前证据状态。官方记录可高置信证明其记录了某个动作/政策，但不能自动证明执行效果或第三方因果。
- 中文转述印尼语原文时标为翻译/概括，待独立复核。英文外交电报摘录也按其情报/政策语境评价。

## 保存范围

首轮以稳定链接、档案号、文档号、段落/页码定位和短摘要为主；不复制整本有版权著作。来源全文可合法保存时，再按许可证、隐私和公开仓库性质决定是否保存原件。全文不可访问、付费墙、未解密或搜索失败均单列，不写成“已查完”。
