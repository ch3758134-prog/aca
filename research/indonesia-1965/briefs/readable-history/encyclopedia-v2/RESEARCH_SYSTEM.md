# V2 研究系统设计与9分准出（第53轮，2026-11-27）

继承原有研究原则和 REBUILD_AUDIT 第35轮准出条件。本文是对工作系统的重新梳理，不替代原始证据、读者正文或历史解释，也不改变长期 OPEN-ENDED GOAL。当前基线为第52轮审计记录；8.3是既有内部暂定评分，不是独立学术验收。

## 1. 研究对象与边界
以印度尼西亚共产主义运动及其真实社会环境、组织关系和历史变化为核心；非共产主义工会、民族主义、宗教社团、妇女与农民组织、政府机关、军队、企业和外部国家具有各自历史，不因与PKI接触而失去独立性。地理及时代范围随解释需要延伸，不把爪哇或中央领导层当作全国。时间是历史行动的坐标，不是预设事件清单；不可由后来的镇压、胜败或政治结论倒推早期行为和动机。

## 2. 知识模型与读者任务
- 最小事实是带定位、来源形成条件、时间范围、地点和置信限制的具体主张；原话、报道、法律规定、执行、结果、因果推论彼此分离。
- 人物档记录姓名异写、身份、职业、生计和任职变动；同名不自动合并，缺名不虚构。组织档记录创立、章程、层级、财务、普通成员、组织决定、分裂和延续；党员、群众组织会员、同情者、选民和行政分类不互换。
- 人与组织联系按性质、起止日期和证据建模。人员共现、任职、正式隶属、协调、资金、命令与实际行动分别处理。制度文本和组织决议仅能证明其规定或表述，除非有实施证据。
- 历史正文按具体社会过程组织，使读者理解生计、经济条件、行动者和选择如何改变。人物、组织、事件独立入口与正文互链，资料台账为后台，不把待查问题或表格代替历史。
- 来源ID不是独立文献数；一个原件的转载、翻译、论文引用应标记依赖关系。原件可读、目录、摘要、学术转引、口述与同期报道分层；同一来源中的不同说法也可并列。
- 对冲突不强求唯一日期或唯一解释，注明分歧、形成条件及验证路径。保留确知、未知与可能性；不得以缺证等同否定，也不得把可能性当事实。

## 3. 研究与交付循环
定位影响理解的具体缺口 -> 查正式C/S与现有正文避免重复 -> 跨语种检索文献 -> 核原件内容/页码与出处依赖 -> 修正或登记具体主张 -> 同步人物/组织/关系/事件及连续中文正文 -> 生成离线HTML并验证 -> 独立审查正文、证据、弱覆盖与交付。更新分支不触碰main。资料未得明确标记；不将新增索引、搜索命中或CI成功等同历史进展。不得为了评分强行增加无关引用。

## 4. 9分准出
维持既有六维审计：可追溯性、史料批判、人物组织关系、连续社会经济史、跨岛普通成员与家庭、HTML可用性。沿用原审计，不设新权重来制造分数。至少满足：核心争议的具体证据和来源依赖可复核；薄弱正文实质补证；几个外岛的普通成员—职业/土地—组织—政治变故—家人或后续制度变化具连续证据；高风险身份/日期/数字/因果独立复查；当前HEAD生成与浏览器、打印、无障碍、跨浏览器等实际验收；明确仍无法取得的原件和史实边界。关键维度短板不能被其他维度高分掩盖。9分是阶段性质量准出，不是历史穷尽。

## 5. 本阶段优先级
第52轮审计列出11段薄弱正文。优先补1980年代拘押后制度（pr-035）、1924党组织与西苏门答腊地方文书（pr-005b/011/012c）、殖民流放个人履历（pr-014a）、Gerwani财政与土地实践（pr-023a/027a）、具体工会拘押者与家庭（pr-035a/c）、口述史与跨岛研究网络（pr-038a/b）。同时对影响全局理解的1965决策/地区机制等核心争议并行复查。弱引用计数仅是排序提示，不是9分判据。
