## 对上一个版本的实质改进

1. **主阅读页现以45条关联的历史过程为基础**，不再默认使用原来14个目标式大章节。每条尽量同时交代当时可证明的参与者及其组织、物质活动、机构变化、行动、同期可观察的结果与史料边界；这些记录还不等于完整历史。
2. **旧14章保留为次级备查**，以避免删掉尚未吸收的细节；从主阅读页可直接打开它。
3. **组织不是静态标签**：48个基础组织与机构档案；其中包括SI全国机关与三宝垄分会、Gerwis与Gerwani、PKI正式政治局与特别局、九三〇行动网络与其公开宣布的革命委员会、PNI中央与内部反对派。30条组织间关系注明性质。
4. **人员身份不倒填**：当前整理62条有对应日期的任职/参与记录，并将旧65人扩展到120个人物索引。见到“出席秘密会议”不等于有中央委员身份；见到工会会员不等于PKI党员。索引不是完整名册。
5. **原研究资产全量保全并可检索**：2,877条事实主张、1,527条来源、664条覆盖/缺口记录、53项旧事件，保持原有证据边界和原始数据行。来源登记的完整文件并不一定表示来源全文已读。
6. 主阅读为简体中文；底层事实主张仍保留登记时的英文原文，防止未核翻译覆盖既有证据。

## 不能绕过的历史要求

- 研究时使用实际活动和组织关系的发展确定叙述单元；日期是证据属性，不能先定“阶段”或最终结局。
- 人、组织、成员资格、任职、参会、政治同情、一般群众活动和军事指挥权分别表达；每一项关系必须有适用日期。
- 同一组织的不同地方支部可能不同步，不允许把总部的章程当作所有基层实际执行。
- 引用后出供述、审判记录、党派自己发表的数字与政府主张时，必须保留说话者及记录形成的制度环境。
- 史料与事实台账里的编号不是完成证明，空白处明确保留“尚未取得原始材料”。
- 任何新版百科发布不得覆盖或删除旧史料/事实/详细历史正文。

## 限制与下一轮调查

目前的45条历史过程主要是把已搜集到、已标引的历史材料重新关联，没有做到各省县全部地方支部、行业工会、村庄土地档案以及党内所有会议逐人名册的全面复原。一些过程尚未挂接单项事实ID；界面会明确显示。

最重要的继续工作是：早期1910—1927逐地工会及SI/PKI支部成员、1945—1951左翼各党派及劳动社团的人事/联合会议、1951—1965中央与各省党组织/群众组织的日常制度、1965—1968全国地区差异、1970年后工会和家属网络的实际延续；还应补充其他社会组织的独立历史，不把它们当作PKI背景板。
