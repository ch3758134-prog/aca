# 面向作者阅读的连续历史正文

该目录存放可以**直接顺读**的中文历史文字（HTML）。不是史料目录、检索日志、简报或论文大纲。

- 以真正发生的过程、各方人物和机构的关系、前因后果为叙述中心。
- 材料分批搜集，但**不按检索批次机械生产HTML**；积累足以解释某一过程的材料后，写成连续正文。
- 暂时可以只有一段历史；未写的年代不得用资料堆砌或猜测补齐，必须明确当前覆盖范围。
- 文中必要的小注释指向来源ID，完整证据级别、争议与下一步在后台CSV和Markdown里。
- 原有 `briefs/phase-fact*.html` 属于旧式快照，已按照作者要求从 `main` 删除。对应史料台账仍保留；**不要重新生成旧式HTML**。
- 作者的政治判断、文章最后立场由作者本人确定。

目前已有一份跨时期连续阅读版和多篇地方/专题深读章节。连续阅读版串联当前有材料支持的历史过程；它仍有年代和地区缺口，不能当作整部印尼左翼史已经完成。
