# 项目工作规则

## 项目目标

本项目使用证据驱动的通用写作流程，当前案例暂定为1965年前后印度尼西亚历史，重点包括苏加诺时期的政治结构、1965—1966年权力变化、社会暴力，以及外国行动者的介入渠道和操作机制。具体范围以 `project/brief.md` 和用户最新指示为准。

## 分阶段读取与检索

- 每次任务开始先确认当前阶段，并读取 `project/stage-access.md` 中该阶段的允许材料清单。
- 用户为本次任务明确给出的文件、资料范围和排除项优先。未获准的资料不得打开、检索或用其他渠道绕过。
- 如果允许路径未填写，先只读取任务指示、`AGENTS.md` 和阶段清单；向用户说明缺少哪些材料范围。可以继续做不依赖该范围的工作。
- “可读材料”和“可检索来源”分别登记。不能因为文件已在项目目录里，就默认当前阶段可以读。
- 此文件和清单只约束模型行为，不能提供技术访问控制。需要硬隔离时，使用分开的目录、工作区或单独上传的材料。

## 事实、分析与政治判断

- 将内容标成 `[事实主张]`、`[分析]`、`[评价]` 或 `[作者判断]`。一个句子包含多种内容时拆分记录。
- 事实主张必须关联来源 ID 和精确定位信息；没有找到来源时标为“待核实”，不得补写看似可信的出处。
- 区分来源本身的可靠程度、事实主张的置信度、因果关系的置信度。官方文件、学术著作、回忆录、媒体材料都需要考察形成背景和局限。
- 同一主张存在相反证据时并列登记，不得静默删去、合并或改写成确定结论。
- 作者的基本立场尚未提供。不得根据用户的主题、词汇或预设立场代填。政治评价标准由作者书面确认；AI 可以整理选项、指出矛盾和证据缺口，但不得冒充作者给出立场。
- 文章中的明确政治判断应能追溯到已确认的事实、分析链条和作者明确认可的评价标准。

## 留档标准

- 按仓库根目录 `.agents/skills/evidence-led-writing/references/archive-standard.md` 执行。
- 新来源先分配稳定的来源 ID；事实主张、时间线、分析备忘录和草稿都引用该 ID。
- 记录原始检索式、数据库或档案馆、检索日期、过滤条件、检查过的结果、纳入与排除理由和后续检索计划。
- 保留原文标题、作者/机构、形成日期、出版日期、语言、档案号/页码/时间码、稳定链接及访问日期。引用原文时保留上下文；翻译与原文分开标记。
- 修订时新增版本或修订日志，不覆盖原始证据记录。无法保存全文时，记录无法留存的原因和可复查定位信息。

## 写作与交付

- 先提交事实材料和争议点，再形成分层分析，最后在作者确认立场后起草政治判断。
- 草稿中的重要事实应有可追溯引文；引用页码、档案号、链接或时间码，不能只写书名或机构名。
- 发现新事实时先回到来源登记和事实核验阶段，再更新分析和草稿；不得在写作阶段悄悄引入未审查材料。
- 每阶段记录输入范围、完成内容、未解决问题和下一步。没有实际执行的检索不得写成“已查”。
