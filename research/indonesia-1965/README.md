# 印度尼西亚 1965 研究框架

本目录用于建立1965年前后印度尼西亚历史文章的事实底稿、来源档案、分层分析与作者判断记录。这里是研究框架，尚未开始史料搜集，不包含历史结论。

## 范围与原则

- 核心时段暂定1965—1966年，背景时段1957—1965年9月，后续观察至1968年。
- 重点研究苏加诺、军方、PKI、其他政治力量、社会冲突，以及外国行动者可能采用的介入渠道。
- 事实、分析和政治判断分开留档；作者基本立场由作者本人填写，不从题目推断。
- 各阶段按 `project/stage-access.md` 指定 AI 可读文件和可检索范围。

## 文件

- `AGENTS.md`：仅适用于本研究目录的 Codex 项目规则。
- `project/brief.md`：研究问题和暂定范围。
- `project/author-position.md`：作者立场模板，目前留空。
- `project/stage-access.md`：阶段访问与检索清单。
- `templates/`：来源登记、主张台账、检索日志、覆盖矩阵、时间线、分析备忘录、决策日志和文章提纲。
- 仓库通用写作 Skill：[`../../.agents/skills/evidence-led-writing/SKILL.md`](../../.agents/skills/evidence-led-writing/SKILL.md)。

真实访问隔离需要将未开放材料放在单独目录、工作区或仅按阶段提供；提示文件本身不是操作系统权限。
