# 印度尼西亚 1965 历史研究

本项目围绕1965年前后印尼政治转折建立事实档案和可追溯分析。研究没有固定的前史起点：如解释需要，可追溯苏加诺家庭、履历、政治关系、反殖民运动、革命史和更早制度；后续史也可按问题延伸。范围扩展和检索路径写入 `project/scope-change-log.md` 与 `archive/records/search-log.csv`。

## 当前工作状态

当前为首轮来源发现和事实核验，研究仍在进行。首批档案包括来源登记、主张台账、检索日志、覆盖矩阵、时间线、人物关系和外国介入渠道矩阵，见 `archive/records/`。检索结果区分已打开原文、只看摘要/元数据、发现但尚未核查的材料。

## 研究边界

- 核心问题围绕苏加诺、1965年9月末事件、军方夺权、1965—1966年暴力与拘押、外国介入机制和权力变化。
- 可按证据扩展到任何相关时期、人物与关系，不因“太早”或不在旧定年范围而排除。
- 事实、分析、作者政治判断分别留档。作者的基本立场由作者提供；目前不读取 `project/author-position.md`，不替作者作政治判断。
- 每一条事实主张链接到来源ID及可复查定位；对于意图、实施、效果、责任和因果分别核查。
- `project/stage-access.md` 记录阶段访问规则和本次明确授权的检索范围。

## 主要文件

- `AGENTS.md`：研究目录规则。
- `project/brief.md`：动态问题和无固定年代边界的范围。
- `project/scope-change-log.md`：用户授权的范围变动及理由。
- `project/stage-access.md`：各阶段读取/检索范围。
- `project/author-position.md`：作者立场模板，暂未开放。
- `archive/records/`：研究日志、事实台账、来源目录、时间线和行动者档案。
- `templates/`：后续工作模板。
- 通用 Skill：[`../../.agents/skills/evidence-led-writing/SKILL.md`](../../.agents/skills/evidence-led-writing/SKILL.md)。

本项目不会把任何一个检索平台、国家档案馆或年代区间说成全部史料。检索覆盖状态与盲区必须随研究推进更新。
